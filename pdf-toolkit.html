Is my PDF uploaded?

No — not for any tool on this page.

Your PDF is processed directly in your browser using JavaScript. It does not need to be, and is not, uploaded to Salman IT Tools for any of the tools below. Nothing is stored: once you leave or refresh this page, the file and every result are gone, because there was never a server-side copy to begin with.

If a future tool ever needs to use a server, it will be clearly marked and you'll be asked first — this blanket privacy statement will never quietly stop being true.

🔐 Protect / Unlock PDF — Coming Soon

Password protection and removal aren't available yet.

Reliable PDF password protection needs strong encryption, and we haven't yet found a browser-based library we're confident is safe and correct enough to ship here. Rather than fake it — you'd never actually get a genuinely protected file — we're leaving this tool out until it works properly.

In the meantime, most PDF viewers can do this natively: Adobe Acrobat, macOS Preview (File → Export as PDF → Encrypt), and Microsoft Word/Print-to-PDF all support setting a password. We never attempt to crack or bypass a PDF password, even a user's own — this feature will only ever unlock a file when you already know the password.
Frequently Asked Questions

Common Questions

Are these PDF tools free?

Yes — every tool in the PDF Toolkit is completely free with no registration, no account and no usage limits.

Are my PDFs uploaded to a server?

No. Every tool on this page processes your PDF directly in your browser using JavaScript. Your file never leaves your device for the standard tools listed here.

Is my PDF stored anywhere?

No. Nothing is saved. Once you close or refresh the page, the file and any results are gone — there is no server-side copy to begin with.

Can I merge multiple PDFs into one?

Yes. Use the Merge PDF tool to combine any number of PDF files, in any order you choose, into a single document.

Can I compress a PDF to make it smaller?

Yes. The Compress PDF tool offers a lossless structural optimisation and an image-based recompression mode for larger reductions, with realistic before/after size reporting — never a made-up percentage.

Can I split a PDF into separate files?

Yes. Split every page into its own file, extract specific pages, or split by page ranges using the Split & Extract tool.

Can I convert JPG or PNG images to a PDF?

Yes. The Image to PDF tool accepts JPG, PNG and WebP images, with options for page size, orientation, margins and image order.

Can I convert a PDF to JPG images?

Yes. The PDF to JPG tool converts every page (or just the ones you choose) into JPG images, bundled into a ZIP file when there's more than one.

Can I remove or reorder PDF pages?

Yes. The Organize Pages tool lets you drag pages into a new order, rotate individual pages, and delete unwanted pages, all with a visual thumbnail view.

Can I rotate PDF pages?

Yes — rotation is built into the Organize Pages tool. Rotate any page 90°, 180° or 270°, individually or several at once.

Can I password protect a PDF?

Not yet in this browser-based toolkit — reliable PDF encryption needs more testing before we ship it. It's marked "Coming Soon" rather than faked.

Can I remove PDF metadata?

Yes. The PDF Metadata tool shows the title, author, creation date and other embedded details, and lets you clear the standard metadata fields before download.

Can I use the PDF Toolkit on my phone?

Yes, every tool is designed to work on iPhone, Android, tablets and desktop browsers, with touch-friendly controls for reordering and selecting pages.
