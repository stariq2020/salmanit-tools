Wi-Fi Connected but No Internet

When Windows shows "Connected" but websites will not open, the fault could be in three different places: your PC, your router, or your internet provider. The fastest way to find out is a single question: do other devices on the same Wi-Fi work? The guide asks that first and then only shows fixes that make sense for the answer.

Start the guided troubleshooterDescribe a different problem

This guide provides general troubleshooting guidance. It cannot directly inspect or repair your computer. Takes about 15–30 min; difficulty: easy; risk: low. Last reviewed 2026-10-13.

Where the fault usually is

  • Nothing works on any deviceThe router, the modem, or the provider. Restarting the router and checking for an outage comes first.
  • Only this PC is affectedA stuck Wi-Fi adapter, stale saved network, VPN or proxy on the PC. Forgetting the network and reconnecting often clears it.
  • Only some websites failUsually DNS (the system that turns website names into addresses). Clearing the DNS cache or testing with ping can confirm it.
  • Internet drops then returnsWeak signal, interference, or an adapter power-saving setting.

Common signs

  • Wi-Fi icon shows a globe or warning
  • "No internet, secured"
  • Browser says "You're not connected"
  • Apps cannot sync

The order we try fixes in

The guided troubleshooter personalises this order from your answers. Here is the general sequence, safest and quickest first:

  1. Switch Wi-Fi off and on againThis forces Windows to renegotiate the connection to the router and clears many temporary glitches. (3 min)
  2. Restart your router and modemRouters run for weeks and can get into a stuck state. (10 min)
  3. Run the Windows network troubleshooterWindows can test your network settings and reset small problems automatically, such as a stuck adapter or wrong settings. (5 min)
  4. Find out where the connection breaksA simple test message can show whether the internet is reachable at all, or whether only name look-ups (DNS) are failing. (5 min)
  5. Forget the Wi-Fi network and reconnectRemoving the saved network deletes possibly corrupt saved settings for that network. (5 min)
  6. Clear the DNS cacheDNS turns website names into addresses. (3 min)
  7. Check for a provider outageIf nothing connects on any device, the fault is often outside your home. (10 min)

Error codes linked to this problem

  • 0x80072ee7 – Server name or address could not be resolvedThe device could not look up an internet name (ERROR_INTERNET_NAME_NOT_RESOLVED). Think DNS or no connection.
  • 0x80072efd – Connection to the server could not be establishedThe device could not connect to the server (ERROR_INTERNET_CANNOT_CONNECT). Check the connection, firewall, proxy or VPN.

Quick answers

What does the 169.254 address mean?

If ipconfig /all shows an IPv4 address starting 169.254, the PC could not get an address from the router. Restart the router and reconnect; the problem is between the PC and router.

What does "Network reset" do?

It removes all saved Wi-Fi networks and VPN adapters and reinstalls network adapters. It can fix deep faults, but you will need your Wi-Fi password again, so it is a last step.

Should I change my DNS settings?

Only as a test. Public DNS can show whether your router's DNS is the problem. Change it back to automatic if it does not help, and do not change DNS on a work PC.

When should I call my provider?

When every device is offline, the router's internet light is red or off, and a restart of the router does not help.

If it is a work or school device

Some of these steps may be blocked by your organisation's policies. If a step is unavailable or asks for an administrator password, stop and contact your IT team. Never share passwords or BitLocker recovery keys.
