Where does my data actually go?

Nowhere near us — this tool is genuinely 100% client-side, in three parts. Site inventory and audit log search: sign in directly with Microsoft, then Microsoft Graph is called from your own browser using your own access token — that includes real audit log records from Microsoft Purview, not just aggregate stats. Storage & usage: Microsoft doesn't allow browsers to fetch those specific report endpoints directly (a restriction on Microsoft's end, not something we can bypass) — so you export them once from the M365 admin center and drop the file in, and it's parsed locally using your browser's file reader. Either way, nothing is sent to or stored on Salman IT Tools' servers. The report only ever exists in your browser tab, and disappears when you close it.

How This Works

1

You sign in with your own Microsoft 365 account using the button above — a standard Microsoft sign-in popup, not a form on this site. Some tenants will ask a Global Admin or SharePoint Admin to approve this the first time.

2

Your browser calls graph.microsoft.com directly using your own token to pull live site inventory — name, URL, template, last activity.

3

Audit log search calls the Microsoft Purview unified audit log via Graph's /security/auditLog/queries API — a query is created, polled until it finishes, then matching records are paged in. This returns JSON with normal CORS headers, so it works directly from a browser.

4

Storage, usage and activity reports normally redirect to a CSV download link that browsers can't follow cross-origin — but requesting them with $format=application/json makes Graph return the same rows inline instead of redirecting, so they're fetched automatically too. If that's ever blocked (usually a missing Reports.Read.All consent), you can export the same report as a CSV from the admin center and drop it in as a fallback; it's parsed with JavaScript's FileReader, entirely on your device.

5

Everything renders locally into the report below. Use "Export / Print Report" to save a branded PDF for a client, or "Export Raw Records" for the full audit log as CSV — nothing is uploaded anywhere in this process.
