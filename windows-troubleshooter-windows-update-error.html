Windows Update Failing or Showing an Error Code

Windows Update failures look alarming, but the cause is usually one of a few things: not enough free space, a damaged update cache, a VPN or proxy in the way, or a driver that does not like the update. The error code narrows it down, so the guide takes it into account. Order matters: simple and reversible steps come first and the technical repairs last.

This guide provides general troubleshooting guidance. It cannot directly inspect or repair your computer. Takes about 45–90 min; difficulty: moderate; risk: moderate. Last reviewed 2026-10-13.

What common update error codes point to

  • 0x80070005 (access denied)Windows or an app was not allowed to change something. Security software or permissions are typical causes.
  • 0x800f0922An installation could not complete. Documented causes include an active VPN, low space on a system partition, or a damaged component store.
  • 0x80073712A file in the Windows component store is missing or damaged. Repair with DISM and sfc.
  • 0x8024402CWindows could not resolve the update server name: check internet, DNS, proxy or VPN.
  • 0xC1900101A feature update was rolled back, often because of a driver or security software.

Common signs

  • "We couldn't complete the updates"
  • Error 0x8007…, 0x800f… or 0xC19…
  • "Install error" in Windows Update
  • The same update keeps retrying and failing

The order we try fixes in

The guided troubleshooter personalises this order from your answers. Here is the general sequence, safest and quickest first:

  1. Restart the PC properlyA restart clears temporary glitches and fully reloads Windows and its drivers. (5 min)
  2. Run the Windows Update troubleshooterWindows can detect and fix common update-service problems automatically. (10 min)
  3. Free up space for the updateUpdates need several gigabytes of working space on the C: drive. (15 min)
  4. Check and repair Windows system filesWindows has a built-in tool that compares protected system files with a stored good copy and repairs damaged ones. (30–60 min)
  5. Reset Windows Update componentsUpdate files in a cache folder can become damaged. (15 min)
  6. Unplug accessories and update driversFaulty drivers and extra devices can cause feature updates to roll back (errors like 0xC1900101). (30 min)

Error codes linked to this problem

  • 0x80070005 – Access denied (E_ACCESSDENIED)Windows or an app was refused permission to read or change something. Common causes include missing administrator rights, security software blocking the action, or damaged permissions.
  • 0x80070057 – The parameter is incorrect (E_INVALIDARG)A generic message meaning a program passed an invalid value to Windows. It appears in many places, including Windows Update, backup and disk tools, so the surrounding context matters.
  • 0x80070002 – File not found (ERROR_FILE_NOT_FOUND)Windows could not find a file it expected. In Windows Update it often points to missing or damaged update files.
  • 0x80004005 – Unspecified error (E_FAIL)A catch-all failure code with no specific cause. Treat it as a symptom: look at what you were doing when it appeared.
  • 0x80073712 – Component store file missing or damagedA file Windows Update needs in the Windows component store is missing or damaged (ERROR_SXS_COMPONENT_STORE_CORRUPT). Repairing the store with DISM and sfc usually comes first.
  • 0x800f0922 – Update installation failed (CBS_E_INSTALLERS_FAILED)A Windows update or feature could not finish installing. Causes documented by Microsoft and support communities include a full System Reserved partition, an active VPN, or a damaged component store.
  • 0x80070643 – Fatal error during installationAn installer, often a Windows or .NET update, reported a general installation failure. Retrying after a restart and repairing system files are the usual first steps.
  • 0x80070422 – Service is disabledA Windows service that the task needs (often Windows Update) is disabled or not running. Starting the service, or resetting update components, may help.
  • 0x8024402c – Update server name could not be resolvedWindows Update could not look up the update server address. Check the internet connection, DNS, proxy and VPN settings.
  • 0xc1900101 – Upgrade rolled back (driver-related)A generic code for a Windows upgrade that was rolled back, frequently linked to incompatible drivers or security software. Disconnecting extra devices and updating drivers are standard first steps.
  • 0x800705b4 – Operation timed outWindows waited for something that did not respond in time. Seen with updates and device operations; the underlying cause varies.

Quick answers

Is it safe to run sfc and DISM?

Yes. They repair Windows system files and do not touch your documents. They need administrator rights and can take 30 minutes or more.

What does resetting Windows Update components do?

It renames the SoftwareDistribution folder so Windows rebuilds it. The old folder is kept, so the step is reversible. It is an advanced step, not for work PCs without IT approval.

Should I download updates from other websites?

No. Use Windows Update, or Microsoft's own Update Catalog if you know exactly which KB you need. Never run updates from emails or pop-ups.

Will I lose files if an update fails?

Normally no, but have a backup before big feature updates. Never switch the PC off while the update is actively writing to disk.

If it is a work or school device

Some of these steps may be blocked by your organisation's policies. If a step is unavailable or asks for an administrator password, stop and contact your IT team. Never share passwords or BitLocker recovery keys.
