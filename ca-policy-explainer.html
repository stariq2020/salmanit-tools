Conditional Access
Policy Explainer

Paste a Conditional Access policy JSON exported from Microsoft Entra ID and get a plain English explanation of exactly what it does — who it applies to, what it requires, and any exclusions.

📋 How to get the JSON

  1. Go to Entra admin center → Protection → Conditional Access → Policies
  2. Open the policy you want to check
  3. Click ... (top right) → View policy in JSON format (or use Graph Explorer / Export)
  4. Copy the JSON and paste it below
