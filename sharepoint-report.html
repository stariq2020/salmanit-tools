Where does my data actually go?

This tool is different from most on this site: it needs live data, so it can't run 100% offline. What it does do: sign you in directly with Microsoft, then call the Microsoft Graph API from your own browser using your own access token. What it never does: send your SharePoint data to, or store it on, Salman IT Tools' servers. The report only ever exists in your browser tab, and disappears when you close it.

🔑 You sign in with Microsoft, not us 📡 Data flows Microsoft → your browser only 🗑️ Nothing saved, no cookies of report data 🧾 Aggregate metrics, not a full audit trail

How This Works

1

You sign in with your own Microsoft 365 account using the button above — a standard Microsoft sign-in popup, not a form on this site.

2

The first time, Microsoft will ask for admin consent to two read-only permissions: Sites.Read.All and Reports.Read.All. Only a Global Admin or SharePoint Admin can grant this.

3

Your browser calls graph.microsoft.com directly using your token to pull site inventory, storage/usage and activity reports.

4

Everything renders locally into the report below. Use "Export / Print Report" to save a branded PDF for a client — nothing is uploaded anywhere in this process.
