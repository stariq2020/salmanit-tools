Why Is My Windows PC So Slow?

A PC that has become slow is rarely "just old". Most of the time one specific thing is holding it back: too many programs starting with Windows, a nearly full drive, a browser using all the memory, or a background update. The quickest fix depends on when the slowness happens, so the guide below asks that first.

This guide provides general troubleshooting guidance. It cannot directly inspect or repair your computer. Takes about 20–45 min; difficulty: easy; risk: low. Last reviewed 2026-10-13.

What usually makes a Windows PC slow

  • Too many start-up programsChat apps, game launchers and updaters add themselves to start-up. They slow down the first minutes after you sign in.
  • A nearly full driveWindows needs free space to work and update. Below roughly 15% free, everything gets slower.
  • Browser tabs and extensionsA browser with dozens of tabs can use several gigabytes of memory on its own.
  • Background workAfter an update, Windows Search, Windows Update and security scans can use the processor for up to an hour.
  • Not enough memory (RAM)Windows 11 is comfortable with 8 GB for light use and 16 GB for heavier multitasking. Less means a lot of slow "swapping" to disk.

Common signs

  • Takes a long time to start
  • Programs are slow to open
  • Web pages are slow to load
  • Everything lags, including typing and mouse movement

The order we try fixes in

The guided troubleshooter personalises this order from your answers. Here is the general sequence, safest and quickest first:

  1. Restart the PC properlyA restart clears temporary glitches and fully reloads Windows and its drivers. (5 min)
  2. See what is using your PC's resourcesTask Manager is Windows' built-in list of everything running. (5 min)
  3. Stop unnecessary programs starting with WindowsMany programs add themselves to start-up and slow down the first few minutes after you sign in. (10 min)
  4. Check free disk space and clear junkWindows needs free space to work with. (10–20 min)
  5. Install pending Windows updatesUpdates fix known bugs and driver problems. (15–45 min)
  6. Run a Windows Security scanUnwanted software can slow a PC, hijack browsers or block connections. (10–20 min)
  7. Check and repair Windows system filesWindows has a built-in tool that compares protected system files with a stored good copy and repairs damaged ones. (30–60 min)

Quick answers

Will a restart really help?

Often, yes. A proper Restart (not Shut down) clears memory and reloads drivers. Fast Startup can keep part of the previous session alive after a shutdown, so only Restart gives a clean start.

Is it safe to disable start-up programs?

Yes. Disabling a start-up item does not uninstall it, and you can re-enable it in Task Manager. Leave security software and anything you do not recognise alone.

How much free disk space should I keep?

Aim for 15-20% free on the C: drive, and at least 20 GB when installing big Windows updates.

Should I use a "PC cleaner" or speed-up program?

Generally no. Most do little that Windows' own tools do not, and some are unwanted software themselves. The built-in Storage settings and Task Manager are enough.

If it is a work or school device

Some of these steps may be blocked by your organisation's policies. If a step is unavailable or asks for an administrator password, stop and contact your IT team. Never share passwords or BitLocker recovery keys.
