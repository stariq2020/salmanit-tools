Frequently Asked Questions

What is FileThermal?

FileThermal is a free Windows disk space analyzer and cleanup tool. It scans the folders or drives you choose, shows what is taking up space, and sorts files into hot, warm and cold based on when they were last modified, so you can quickly see what you have forgotten about.

Does FileThermal upload my files?

No. FileThermal reads file names, sizes and dates only, and everything stays on your PC. Nothing is uploaded and no account is needed.

Does it delete my files?

Not on its own. The Cleanup Centre shows you exactly what it proposes to clear and you review the list before anything is moved. Always check the list before you confirm.

What do hot, warm and cold files mean?

They are groups based on last-modified date. Hot files were changed recently, warm files less recently, and cold files not for a long time. Windows does not reliably record when a file was last read, so cold results are a guide rather than proof that a file is unused.

Do I need to install it?

Yes. Unlike the single-file tools on this site, FileThermal is a normal Windows installer (about 106 MB). Run it, choose an install folder and it adds a shortcut. You can uninstall it from Windows Settings at any time.

Why does Windows show a SmartScreen warning?

The installer is not signed with a paid code-signing certificate. Click More info then Run anyway. You can compare the SHA-256 checksum on this page with the file you downloaded.

Which versions of Windows are supported?

Windows 10 and Windows 11, 64-bit.

Is FileThermal free?

Yes, it is free to download and use.
